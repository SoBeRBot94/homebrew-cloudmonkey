# homebrew-cloudmonkey
Homebrew tap for [CloudMonkey](https://github.com/apache/cloudstack-cloudmonkey), The Apache CloudStack CLI

## Install

```sh
brew install SoBeRBot94/cloudmonkey/cloudmonkey
```

Or:

```sh
brew tap SoBeRBot94/cloudmonkey
brew install cloudmonkey
```

## Update

```sh
brew upgrade cloudmonkey
```
